TARS is an AI-based system for Human Activity Recognition in on-board BAS experiments, developed for Smart India Hackathon 2026 under the Space Technology theme.

The system uses fixed cameras, YOLOv11, MediaPipe, 3D Human Mesh Recovery, a state-machine-based validation system, Piper Neural TTS, and modular JSON-based experiment protocols to monitor astronaut actions locally.

TARS is designed for edge-native operation, hands-free guidance, protocol validation, and automated timestamped documentation — addressing challenges such as communication delays, bandwidth limitations, microgravity tracking, and constrained onboard computing.

Run the space.html file to run the entire program on your local system, wait for few seconds so that all the modules can load and then start the camera for activity monitoring
